🚀 INICIO RÁPIDO (5 MINUTOS):

PASO 1: Instalar Python (si no lo tienes)
   → Descargar desde: python.org
   → Marca: "Add Python to PATH"

PASO 2: Instalar librerías
   → Abre terminal/CMD
   → Ejecuta: pip install openpyxl msoffcrypto-tool

PASO 3: Descargar CSV de SFMC (diario)
   → SFMC → Contacts → Data Extensions
   → Busca "de-sol-forms"
   → Click en "Download" → CSV
   → Guarda en: C:\Reportes\Telcel\leads_diarios.csv

PASO 4: Ejecutar script
   → Terminal/CMD
   → cd C:\Reportes\Telcel\Scripts
   → python generar_reportes.py

✅ LISTO. Se generarán los Excel encriptados en:
   C:\Reportes\Telcel\Excel_Generados\

📊 QUÉ GENERA EL SCRIPT:

Para cada ejecución, crea (solo las regiones con leads):

1. Archivos Excel encriptados (hasta 11)
   ├─ R1-leads-calificados-x-dia-r1-2026-03-12.xlsx 🔒
   ├─ R2-leads-calificados-x-dia-r2-2026-03-12.xlsx 🔒
   ├─ R3-leads-calificados-x-dia-r3-2026-03-12.xlsx 🔒
   ├─ ... (solo R4-R9 si tienen leads)
   ├─ MM-tel-leads-mobile-marketing-2026-03-12.xlsx  🔒  (si hay MOM)
   └─ BI-tel-leads-business-intellig-2026-03-12.xlsx 🔒  (si hay BUI)

2. Archivo de contraseñas del día
   └─ CONTRASEÑAS_12032026.txt
      R1  :  R1TELABC
      R2  :  R2TELX4F
      ...
      MOM :  MOMTELQ7R
      BUI :  BUITELW2P

   Nota: Contraseñas ALEATORIAS (no predecibles, cambian cada ejecución)

💡 CARACTERÍSTICAS INTELIGENTES:

1. CLASIFICACIÓN AUTOMÁTICA
   • Si SolucionInteres contiene "Mobile Marketing" o es "MOM" → Archivo MOM
   • Si SolucionInteres contiene "Business Intelligence" o es "BUI" → Archivo BUI
   • Si no → Se clasifica por campo Region (R1-R9)

2. CONTRASEÑA ALEATORIA POR REGIÓN
   • Formato: {REGION}TEL{3 chars aleatorios A-Z/0-9}
   • Ejemplo: R1TELABC, R2TELX4F, MOMTELQ7R
   • Cambia en cada ejecución (completamente aleatoria)
   • Guardada en CONTRASEÑAS_DDMMYYYY.txt

3. ENCRIPTACIÓN REAL DE EXCEL
   • Usa msoffcrypto-tool para encriptar el archivo
   • El Excel pide contraseña al abrirse
   • Si msoffcrypto-tool no está instalado: Excel se crea sin encriptar
   • Estado mostrado en consola: 🔒 PROTEGIDO o ✅ CREADO

4. VALIDACIÓN DE FECHAS MULTI-FORMATO
   • Solo incluye leads creados AYER (basado en campo CreatedAt)
   • Soporta formatos: YYYY-MM-DD HH:MM:SS, M/D/YYYY H:MM:SS AM/PM, etc.
   • Si no hay leads ayer → Muestra advertencia y no genera archivos

5. FORMATO PROFESIONAL EN EXCEL
   • Headers azules (color #00529B)
   • Texto blanco en headers
   • Bordes en todas las celdas
   • Ancho automático de columnas (mínimo 20 chars)
   • Info de generación al pie de cada hoja

CONTRASEÑAS Y ENCRIPTACIÓN:
• Los Excel SÍ se encriptan con contraseña real (usando msoffcrypto-tool)

❓ PREGUNTAS FRECUENTES:

P: ¿Necesito hacer algo todos los días?
R: SÍ - Necesitas exportar el CSV de SFMC diariamente (toma 30 segundos)
  Y enviar los emails manualmente (toma ~10 minutos)
  El script se ejecuta automático a las 9 AM

P: ¿Qué pasa si no hay leads del día anterior?
R: El script muestra: "⚠️  No hay leads para el día anterior"
  No genera archivos y termina normalmente

P: ¿Puedo cambiar la hora de ejecución?
R: SÍ - Edita config.json: "hora_ejecucion": "10:00"
  Luego reinicia la tarea programada

P: ¿Los Excel están encriptados?
R: SÍ - Con msoffcrypto-tool. Al abrir el Excel, pide contraseña.
  Si msoffcrypto-tool no está instalado, se guarda sin encriptar
  (aparece "✅ CREADO" en lugar de "🔒 PROTEGIDO" en consola)
  Instalar: pip install msoffcrypto-tool

P: ¿Cómo son las contraseñas?
R: Aleatorias por región: formato {REGION}TEL{3 chars} ej. R1TELABC
  Diferentes por región, cambian en cada ejecución
  Se guardan en CONTRASEÑAS_DDMMYYYY.txt

P: ¿Cómo sé a qué ejecutivo enviar cada región?
R: Consulta config.json → sección "regiones" → ejecutivos de cada región

P: ¿Puedo automatizar el envío de emails también?
R: SÍ - Usando la librería smtplib de Python o SFMC Triggered Send
