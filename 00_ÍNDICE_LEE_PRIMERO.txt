⚡ INSTALACIÓN ULTRA RÁPIDA (5 MINUTOS):

Windows:
  1. Instala Python 3.12+ (python.org)
  2. pip install openpyxl msoffcrypto-tool
  3. Copia archivos a C:\Reportes\Telcel\Scripts\
  4. Click derecho → instalar_scheduler_windows.bat → Ejecutar admin
  5. ✅ Listo

Linux/Mac:
  1. pip install openpyxl msoffcrypto-tool
  2. chmod +x instalar_scheduler_linux.sh
  3. sudo ./instalar_scheduler_linux.sh
  4. ✅ Listo

Luego:
  • Cada día exporta CSV de SFMC
  • Script se ejecuta automático a las 9 AM
  • Envías emails manualmente
