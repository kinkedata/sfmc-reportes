DISTRIBUCIÓN DE LEADS (Automático según campo Region/SolucionInteres):

        LEADS CON SolucionInteres = "Mobile Marketing"
        └─ → Clasificados en archivo MOM

        LEADS CON SolucionInteres = "Business Intelligence"
        └─ → Clasificados en archivo BUI

        LEADS SIN Mobile Marketing / Business Intelligence
        └─ → Clasificados por campo Region (R1, R2, ..., R9)

        LEADS SIN región válida → Ignorados

puedas consultar a quién enviar cada archivo. El script los lee al inicio.

INSTALACIÓN RESUMIDA:

Windows:
1. pip install openpyxl msoffcrypto-tool
2. Click derecho → instalar_scheduler_windows.bat → "Ejecutar admin"
3. Done ✅

Linux/Mac:
1. pip install openpyxl msoffcrypto-tool
2. chmod +x instalar_scheduler_linux.sh
3. sudo ./instalar_scheduler_linux.sh
4. Done ✅

Uso diario:
1. Exporta CSV de SFMC → C:\Reportes\Telcel\leads_diarios.csv
2. (Script se ejecuta automático a las 9 AM)
3. Abres CONTRASEÑAS_*.txt para ver contraseñas del día
4. Por cada región con leads: Copia destinatarios de config.json → Gmail
5. Adjuntas Excel (protegido) + escribes contraseña en el cuerpo → Envías
