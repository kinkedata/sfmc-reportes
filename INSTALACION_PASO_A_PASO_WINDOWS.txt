## PASO 1: Instalar Python (Si no lo tienes)

1. Abre navegador → google.com
2. Busca: "python download"
3. Entra en: python.org (sitio oficial)
4. Haz clic en: "Downloads" → "Windows"
5. Descarga: "Python 3.12.x" (última versión)

6. Abre el instalador descargado
7. IMPORTANTE: Marca la casilla "Add Python to PATH"
   ┌─────────────────────────────────────────┐
   │ ☑ Add Python 3.12 to PATH              │  ← MARCA ESTO
   └─────────────────────────────────────────┘
8. Haz clic en "Install Now"
9. Espera a que termine (2-3 minutos)
10. Haz clic en "Close"

✅ Verificar instalación:
   - Presiona: Windows Key + R
   - Escribe: cmd
   - Escribe: python --version
   - Debe mostrar: Python 3.12.x
   - Si yes, LISTO ✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PASO 2: Crear Carpetas

1. Abre Explorador de archivos (Windows + E)

2. En tu disco C:, crea la estructura siguiente:

   C:\Reportes\
   └─ Telcel\
      ├─ Scripts\           ← Aquí van los archivos del sistema
      └─ Excel_Generados\  ← Aquí se guardarán los reportes

3. Paso-a-paso:
   a) Click derecho en C:\ → Nueva carpeta
   b) Escribe: Reportes
   c) Enter
   
   d) Abre la carpeta Reportes (doble clic)
   e) Click derecho → Nueva carpeta
   f) Escribe: Telcel
   g) Enter
   
   h) Abre la carpeta Telcel
   i) Click derecho → Nueva carpeta
   j) Escribe: Scripts
   k) Enter
   
   l) Repite para crear: Excel_Generados

Resultado final:
C:\Reportes\Telcel\
├─ Scripts\
├─ Excel_Generados\
└─ leads_diarios.csv  ← Aquí descargarás el CSV de SFMC

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Descargaste 8 archivos (ya tienes un ZIP o están en tu PC)

2. Copia estos 8 archivos a C:\Reportes\Telcel\Scripts\:
   
   ✓ generar_reportes.py

Resultado:
C:\Reportes\

      ├─ config.json

      ├─ (... otros archivos)

## PASO 4: Instalar las Librerías Python Necesarias

1. Presiona: Windows Key + R
2. Escribe: cmd
3. Presiona: Enter (se abre ventana negra - CMD)

4. Copia y pega este comando:

   pip install openpyxl msoffcrypto-tool

5. Presiona: Enter
6. Espera a que termine (puede tardar 1-2 minutos)

Output esperado:
   Successfully installed openpyxl-3.x.x msoffcrypto-tool-x.x.x

Nota: msoffcrypto-tool es el que permite encriptar los Excel con contraseña real.
Si no se instala, los Excel se generan sin encriptar.

✅ LISTO

## PASO 5: Personalizar config.json

1. Abre Bloc de notas (o VS Code/Notepad++)

2. Abre archivo: C:\Reportes\Telcel\Scripts\config.json

3. REVISA estos valores (probablemente estén correctos):
   
   - "csv_entrada": debe apuntar a C:\Reportes\Telcel\leads_diarios.csv
   - "carpeta_salida": debe apuntar a C:\Reportes\Telcel\Excel_Generados
   - "hora_ejecucion": debe ser "09:00"
   
   Si están correctos, no cambies nada.

4. VERIFICA los ejecutivos de tu región en "regiones":
   
   Busca tu región (ej: R1) y verifica que los emails sean correctos:
   {
     "R1": {
       "nombre": "Región 1",
       "ejecutivos": {
         "junior": "ignacio.sanchez@telcel.com",  ← Actualiza si es necesario
         "senior": "melpadsa@telcel.com"          ← Actualiza si es necesario
       }
     }
   }
   
   Si cambias algo, guarda el archivo (Ctrl+S).

5. Cierra el archivo

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## PASO 7: Instalar Automatización (Task Scheduler)

IMPORTANTE: Este paso hace que el script se ejecute automáticamente a las 9 AM
cada día.

1. Abre Explorador → C:\Reportes\Telcel\Scripts\

2. Busca el archivo: instalar_scheduler_windows.bat

3. CLICK DERECHO en el archivo

4. Selecciona: "Ejecutar como administrador"
   
   (Si ves ventana de permiso, haz clic en: "Sí")

5. Se abrirá una ventana CMD negra mostrando progreso

Output esperado:
   ========================================
   Configurador de Automatización - Telcel
   ========================================
   
   [OK] Ejecutando como administrador
   
   [*] Creando tarea programada...
   
   [OK] Tarea creada exitosamente!
   
   Detalles:
     - Nombre: TelcelReportesAuto_9AM
     - Hora: 09:00:00 (09:00 AM)
     - Frecuencia: Diaria
     - Script: generar_reportes.py

6. Presiona cualquier tecla para cerrar la ventana

✅ LISTO - La tarea está instalada

VERIFICACIÓN:
1. Presiona: Windows Key + R
2. Escribe: taskmgr
3. Presiona: Enter (abre Task Manager)
4. Haz clic en pestaña: "Task Scheduler Library" (si está disponible)
   O: Busca en Control Panel → Task Scheduler
5. Debes ver la tarea: TelcelReportesAuto_9AM

✅ Confirmado - Se ejecutará automáticamente mañana a las 9 AM

## PASO 9: Exportar CSV Real de SFMC

Mañana (o cuando necesites hacer el primer reporte real):

1. Abre SFMC (Salesforce Marketing Cloud)
   Dirección: https://mc.YOUR_INSTANCE.salesforce.com/

2. Navega a:
   Contacts → Data Extensions → "de-sol-forms"

3. Haz clic en: Download
   → Formato: CSV
   → Incluir: Todos los campos

4. Guarda el archivo en:
   C:\Reportes\Telcel\leads_diarios.csv
   
   (Sobrescribe el archivo anterior)

5. El script se ejecutará automáticamente a las 9 AM y generará los reportes

## PASO 10: Workflow Diario (A partir de mañana)

MAÑANA A LAS 9 AM (Automático):
1. Script se ejecuta automáticamente
2. Lee CSV de SFMC
3. Genera 11 Excel
4. Crea instrucciones de email

MAÑANA DESPUÉS DE LAS 9 AM (Manual):
1. Abre: C:\Reportes\Telcel\Excel_Generados\CONTRASEÑAS_DDMMYYYY.txt
   (Para ver las contraseñas aleatorias de cada región)

2. Para cada región con Excel generado:
   a) Consulta config.json para saber a quién enviar cada región
   b) Abre Gmail en el navegador
   c) Haz clic en "Redactar"
   d) Escribe los destinatarios (TO y CC según config.json)
   e) Escribe el asunto y cuerpo del email
   f) Menciona la contraseña en el cuerpo del email
   g) Adjunta el Excel correspondiente (ej: R1-leads-...-YYYY-MM-DD.xlsx)
   h) Haz clic en "Enviar"

3. Repite para cada región que tenga leads

✅ LISTO - Emails enviados
